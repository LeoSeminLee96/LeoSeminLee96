Areas of interest include:

- Condition Assessment
- Fault Diagnosis
- Maintenance Automation
- Repair Automation
- Remanufacturing
- Product Lifecycle Engineering
- Circular Manufacturing

Real-world disassembly and repair are fundamentally different from repetitive factory automation.

Components may be:

- damaged,
- deformed,
- corroded,
- partially missing,
- assembled differently,
- difficult to identify,
- or impossible to handle using a fixed sequence.

This makes the problem particularly interesting from the perspective of **perception, planning, reasoning, manipulation, and decision-making under uncertainty**.

# 🔐 Cybersecurity

My interest in cybersecurity grew primarily from **software development and systems engineering**.

While building and studying software, I became increasingly interested in questions such as:

- Why does a system fail?
- What assumptions does its architecture depend on?
- How can those assumptions be violated?
- How does unexpected input affect system behavior?
- How should a system be redesigned to become more robust?

Areas I continue to study include:

- Software Security
- Systems Security
- Vulnerability Analysis
- Reverse Engineering
- Program Analysis
- Embedded Security
- Robotics Security
- Cyber-Physical Security
- Secure System Architecture

I view cybersecurity as a **cross-cutting engineering concern**, particularly for systems where software controls physical processes.

In cyber-physical systems, security failures may no longer remain purely digital — they can affect **machines, infrastructure, equipment, and people**.

For this reason, I am interested in designing systems with:

> **Security + Safety + Reliability + Fault Tolerance**

considered together.
